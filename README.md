# UPPCL Feeder Energy Audit Dashboard

Comprehensive 11KV Feeder Energy Audit Dashboard for Uttar Pradesh Power Corporation Limited (UPPCL).

- **Year-on-Year Comparison**: 2026-27 vs 2025-26 (April to August)
- **Feeder Coverage**: 26,033 feeders across all Discoms (PVVNL, DVVNL, MVVNL, PUVVNL, KESCO)
- **Key Metrics**: Input Energy, Energy Billed, Billing Efficiency, Collection Efficiency, AT&C Loss, Line Loss, Average Billing Rate, Amount Assessed, Amount Realised, AT&C Loss Value
- **Interactive Multi-Level Drilldowns**: Discom ? Zone ? Circle ? Division ? Substation ? Feeder

Hosted permanently on GitHub Pages: https://pranav130.github.io/uppcl-feeder-audit/
